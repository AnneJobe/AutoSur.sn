\## 4. Règles d'analyse



Avant de reprendre un élément d'un dépôt :

1\. Examiner son code source.

2\. Vérifier sa licence.

3\. Vérifier les technologies et versions utilisées.

4\. Identifier les fonctionnalités réellement disponibles.

5\. Déterminer leur utilité pour AutoSur.sn.

6\. Documenter les adaptations nécessaires.



Aucun code externe ne doit être intégré sans analyse préalable.
